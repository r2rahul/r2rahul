Can you describe what “only unison sync is working” means exactly? A few possibilities:

  • The onedrive --sync part runs but doesn’t actually upload/sync the files?
  • The command exits after unison and never reaches the onedrive part?
  • You see no error but OneDrive isn’t reflecting the changes?

One thing worth checking: unison returns a non-zero exit code even on a successful sync in some cases (e.g., when files changed on both sides), which would cause && to skip the onedrive step. You could change && to ; to always run the OneDrive sync regardless of unison’s exit code:

alias note_sync="unison -batch -ignore 'Name .obsidian' /home/r2rahul/koshloc/ /home/r2rahul/OneDrive/kosh ; onedrive --sync --single-directory \"kosh/\""
alias plan_sync="unison -batch -ignore 'Name .obsidian' /home/r2rahul/career-plan /home/r2rahul/OneDrive/work/career-plan ; onedrive --sync --single-directory \"work/career-plan\""
